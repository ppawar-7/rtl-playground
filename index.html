1. Continuous Assignment (assign)

Used for dataflow modeling of combinational logic. The target must be a wire net. The right-hand side is evaluated continuously whenever any operand changes.

// Combinational dataflow
wire sum, carry;
assign sum   = a ^ b;
assign carry = a & b;
💡 Synthesizes directly into combinational logic gates with zero clock cycle delay.
2. Conditional Selection (? : vs if/else)

The ternary operator sel ? b : a selects between expressions in continuous assignments. Procedural if/else statements can only be used inside always blocks.

// Continuous conditional selection
assign y = sel ? in1 : in0;

// Procedural equivalent (requires reg)
always @(*) begin
    if (sel) y_proc = in1;
    else     y_proc = in0;
end
💡 In hardware, both synthesize to a 2:1 multiplexer standard cell.
3. Multiplexer Patterns with case

When selecting among multiple inputs (e.g., 4:1 or 8:1 MUX), procedural case statements provide clean, scalable RTL descriptions.

always @(*) begin
    case (sel)
        2'b00: y = d0;
        2'b01: y = d1;
        2'b10: y = d2;
        2'b11: y = d3;
        default: y = 1'b0; // Avoid latches!
    endcase
end
⚠️ Always provide a default clause to prevent synthesis of unintended level-sensitive transparent latches.
4. Clocked Logic (always @(posedge clk))

Describes synchronous, edge-triggered state storage. The statements execute strictly when the clock transitions from logic 0 to 1.

reg q;
always @(posedge clk) begin
    q <= d; // Sampled on rising edge
end
💡 Synthesizes to a physical D Flip-Flop (DFF). Retains previous state $Q$ between clock edges.
5. Nonblocking (<=) vs Blocking (=)

Fundamental golden rule of RTL design:

  • Use nonblocking (<=) in clocked always @(posedge clk) blocks. All updates happen simultaneously at clock edge, preventing simulation race conditions.
  • Use blocking (=) in combinational always @(*) blocks.
// 2-Stage Shift Register (Nonblocking is mandatory)
always @(posedge clk) begin
    q1 <= data_in;  // Evaluated simultaneously!
    q2 <= q1;       // Takes 2 clock cycles to reach q2
end
⚡ If blocking = were used here, q2 would erroneously receive data_in in the same cycle!
6. Clock Enable & Synchronous Reset

In ASIC design, never gate the clock net directly (it induces clock skew and glitches). Use recirculating data multiplexing instead:

// Synchronous Reset + Clock Enable pattern
always @(posedge clk) begin
    if (rst) begin
        q <= 1'b0;      // Synchronous reset priority
    end else if (en) begin
        q <= d;         // Load when enabled
    end
    // Implicit: holds previous q when en=0
end
🛡️ Guarantees fully synchronous timing and predictable static timing analysis (STA) closure.
